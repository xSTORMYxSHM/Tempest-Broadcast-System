## About this release

0.20.0 is the first planned public preview of Tempest Broadcast System. It packages the OBS-based broadcast engine as an independently branded workstation with isolated user configuration and a Tempest-oriented production interface.

## Highlights

- Responsive Command and Engineering workspaces with per-display layout profiles
- Scene Control and Source Operations for routing and detailed source work
- Stream Overlay modes, content profiles, message playlists, variables, and modular browser assets
- Audio-reactive overlay telemetry, palettes, presets, and external-event accents
- Asset Library, Overlay Designer, Sequence Director, and native Media Controls
- Application-wide interface scaling, color accents, and dock recovery tools
- Authenticated localhost integration with Tempest Studio for resolved workflow commands
- Independent settings, mutex, executable identity, and updater behavior for side-by-side use with OBS Studio

## Known limitations

- The initial package is unsigned unless the publisher applies a trusted Windows code-signing certificate after packaging.
- Tempest-owned Twitch application credentials are required at build time for OAuth and the authenticated Stream Information dock. Manual stream keys remain usable without them.
- Tempest Studio is optional, but Studio-routed Twitch events and Sound Alerts require a compatible Studio installation.
- AJA and DeckLink modules may log harmless initialization failures when their hardware or vendor runtimes are absent.
- Third-party OBS plugins are not bundled unless a release explicitly lists them; compatibility should be checked against the OBS engine version shown in the application and release manifest.
- This preview still requires clean-machine, common capture-hardware, real-stream, and upgrade-cycle acceptance testing before it should be promoted from prerelease status.
